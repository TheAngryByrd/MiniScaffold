# Triage labels

The engineering skills use five canonical triage roles.

| Skill role        | GitHub label       | Meaning                                      |
| ----------------- | ------------------ | -------------------------------------------- |
| `needs-triage`    | `needs-triage`     | A maintainer must evaluate the issue         |
| `needs-info`      | `needs-info`       | The reporter must provide more information   |
| `ready-for-agent` | `ready-for-agent`  | An autonomous agent can implement the issue  |
| `ready-for-human` | `ready-for-human`  | A person must implement the issue            |
| `wontfix`         | `wontfix`          | The project will not implement the issue     |

When a skill names a role, use the corresponding GitHub label.
